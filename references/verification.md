# 检查与交付

确定用户最重要的流程，并在真实浏览器操作。`scripts/verify_page.py` 需要 Python Playwright 和已安装浏览器；依赖缺失时报告原因，不把跳过写成通过。

- 入口有内容，无 console/page 错误；所用图片和字体加载成功。
- 控件确实改变内容或状态，不以 hover 代替主要流程。
- 桌面及 390/360px 无横向溢出；对话框能关闭，键盘可操作。
- 动画实际变化，暂停停止；reduced-motion 下仍可使用。
- 导出捕获实际文件并解析。file:// 上普通 download 链接可能仅打开文件，应明确区分；Blob 下载可以实际测试。
- 离线交付用 offline 模式加载，记录所有 HTTP 请求；联网业务按真实前提测试，不套用零网络要求。

截图放在用户工作目录的单独 QA 子目录，不写进技能库。哈希和 ZIP CRC 是文件完整性证据，不替代浏览器检查。

复刻额外用真实参考同尺寸对照，说明剩余差异。风格演绎无需声称像素相同。报告通过的关键流程、可打开入口和未验证范围；模板冒烟检查不能保证任意生成产品自动通过。
