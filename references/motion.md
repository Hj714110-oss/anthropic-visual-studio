# 动效与真实交互

按用户要求选强度，不让全部元素同时漂浮。动画应说明状态、引导注意或解释插画隐喻。

| 场景 | 起始方案 | 必须验证 |
|---|---|---|
| 安静的插画首屏 | 整体上下 4–8px，5–7 秒；游标视差约 8px 以内 | 离开归位，暂停停止，触屏无需悬停 |
| 内容进入视野 | opacity 与 12–20px translate，350–600ms，一次即可 | 无 JS 仍可读，滚动不闪烁 |
| 连接/思考 | 小范围节点呼吸、可控路径描边 | stroke 动画用于真实 stroke，不伪装成复杂形状重绘 |
| 滚动叙事 | 同一画面的分段状态变化 | 无滚动劫持，键盘和短屏可达全部内容 |
| 导航/选中 | 150–250ms 颜色、边框或轻位移 | 同步 aria-pressed/aria-current，焦点可见 |
| 复杂互动/物理/3D | 判断是否真的需要专门库 | 沿用已有栈，核实必要依赖；简单漂浮不引入引擎 |

优先 CSS transform/opacity、少量 requestAnimationFrame 和 SVG 分组。分组不代表已具备手指、羽毛等语义骨架。运动必须来自可控制的对象和状态，不能把截图称为动画。

避免无理由的大幅缩放、闪烁、自动声音或正文跟随指针。提供暂停；`prefers-reduced-motion: reduce` 下禁用持续运动和视差，内容与主要操作仍可用。

在两个时间点读取真实变换，确认实际运动；暂停后比较同一对象状态不变；reduced motion 下重复。拖拽、时间轴或滚动动画分别验证起点、中段、终点和恢复操作。截图只辅助检查构图。
