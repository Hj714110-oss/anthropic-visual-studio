# 视觉语言：用于创作的默认值

这些是依据本地材料整理的工作默认值，不是官方设计令牌。用户指定的配色、布局、无障碍要求和产品内容优先。

温暖、理性、有手的痕迹。用清晰的编辑式层级和有目的的留白组织内容；真实插画承担“思考、生长、协作、书写、连接”等隐喻，不是散布在每张卡片里的装饰。

默认纸色 `#f6f3eb`、墨色 `#25241f`、陶土强调 `#c66c4d`、细线 `#cbc6bc`。辅助方案：苔绿 `#7b8566`、麦田 `#b49a70`、暮蓝 `#758895`。一屏通常一个主要强调色；文字与交互状态对比必须可读。

- 拉丁标题用 Anthropic Serif Regular，合理字号与紧凑行距形成层级，避免依赖合成粗体。
- 界面、表单、正文用 Sans；编号、元信息与代码用 Mono。
- 中文标题可用宋体类衬线，正文用微软雅黑/PingFang/系统无衬线回退。混排必须实际截图，不能假设三份字体有中文。
- 布局可选编辑式首屏、作品索引、研究文章、产品工作台；不要固定为英雄区加三张同款卡片。
- 优先细线、轻底色差和精确间距。大面积玻璃模糊、霓虹渐变、重阴影不作为默认组成。

## 插画与复刻

使用现有纯路径 SVG 时保留绘制顺序、透明度和 `viewBox`。调色作用于明确色组，不将全部 fill 无差别替换。`assets/prepared/*.svg` 的 `__INK__`、`__PAPER__`、`__ACCENT__` 是明确的配色角色。

照片、拼贴和纸纹适合位图，不要为了“可编辑”生成数万个路径。用户要求可编辑时，优先拆出明确几何形状，说明还原层级和未矢量化部分。

指定参考的验收分别看：同尺寸构图、字形与断行、主形状轮廓、前景误差、重叠关系、纹理细节。背景面积不能掩盖前景缺陷；统计接近不等于人工审阅通过。保持简短差异清单，只报告真正完成的精修。

## 导出与移植

只复制本次用到的字体和素材，不把整个技能库塞进每个网页。离线页面不依赖远程脚本、字体或图片。保留 TTF 和可编辑文本；设计软件未必读取 SVG 内嵌网页字体，说明实际验证环境。
